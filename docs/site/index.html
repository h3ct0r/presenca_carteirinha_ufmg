Apply config.tar to the SD card

  1. In Config, download config.tar (built entirely in your browser).
  2. Put the file at the root of the device SD card as /config.tar — either copy with a card reader, or join the device Wi‑Fi soft‑AP and use SD File Manager (Admin → Wi‑Fi) to upload it.
  3. On the device: confirm import on idle (new setup) or Admin → Import config. The firmware validates and overlays teachers / students / classes; attendance data is kept.
