Your browser does not support Web Serial. Open this page in Google Chrome or Microsoft Edge on a desktop PC (not on iOS).
  1. Connect the RFID Attendance device (Guition ESP32-P4) with a USB data cable. On battery, press SW3 to power on.
  2. Close any program that uses the USB serial port (PlatformIO monitor, terminal, IDE).
  3. Select a release, acknowledge the risk, click Install, and choose the correct serial port.
  4. This board uses Espressif USB-JTAG. If auto-reset fails, when prompted: hold BOOT → tap RST → release RST → release BOOT (GPIO35 / EN). Leave PlatformIO monitor closed.
