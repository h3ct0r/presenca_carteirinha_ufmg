Before you start

  1. Connect the device with a USB data cable. On battery, press SW3 to power on.
  2. Close PlatformIO monitor / any other serial tool.
  3. Select a release, acknowledge the risk, click Install, then pick the serial port.
  4. If auto-reset fails: hold BOOT → tap RST → release RST → release BOOT.
